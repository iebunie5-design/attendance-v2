# 🎯 아이디어큐브 아름/SW코딩 출결 관리 시스템 v2.0

아이디어큐브 아름/SW코딩 학원 전용으로 설계된 스마트 출결 및 학생 관리 시스템입니다. Next.js와 Supabase를 기반으로 실시간 데이터 동기화와 직관적인 QR 기반 출결 기능을 제공합니다.

---

## 🚀 주요 업데이트 및 해결된 이슈 (v2.0)

이번 업데이트를 통해 관리자 보안 강화, 데이터 정합성 문제 해결, 그리고 사용자 편의성을 대폭 개선했습니다.

### 1. 🔐 관리자 인증 및 보안 강화
*   **어드민 로그인 기능**: Supabase Auth를 통합하여 허가된 관리자만 시스템에 접근할 수 있도록 보안을 강화했습니다.
*   **세션 관리**: 로그인 상태에 따른 페이지 접근 제어(Protected Routes) 및 원클릭 로그아웃 기능을 구현했습니다.

### 2. 📱 스마트 QR 및 수동 출결 시스템 (키오스크 모드)
*   **실시간 QR 스캔**: 학생별 전용 QR 코드를 통한 즉각적인 출결 처리가 가능합니다.
*   **수동 입력 연동 버그 수정**: QR 코드가 없는 학생도 '이름 검색'을 통해 수동 출결이 가능하도록 로직을 개선했습니다.
*   **메뉴 간 실시간 동기화**: 수동 입력 시 반 정보(`class_id`)가 누락되던 문제를 해결하여, 키오스크 기록이 모든 메뉴(대시보드, 통계 등)에 즉시 반영됩니다.

### 3. 📊 데이터 정합성 자동화 (반 관리)
*   **학생 수 자동 집계**: 반 관리에서 학생 수를 수동으로 입력하던 방식을 폐지하고, 학생 관리 DB를 기반으로 실시간 자동 계산되도록 시스템화했습니다.
*   **딥링크(Deep Linking)**: 반 관리의 '상세보기' 클릭 시 해당 반이 선택된 상태로 출결 기록 페이지로 즉시 이동합니다.

### 4. 📝 출결 관리 편의 기능
*   **기록 토글 및 취소**: 잘못된 출석 체크를 방지하기 위해 버튼 클릭 시 상태가 토글(Deselect)되거나 초기화되는 기능을 추가했습니다.
*   **학생 명단 포함 초기화**: '기록 초기화' 시 해당 날짜의 출결뿐만 아니라 필요시 학생 명단까지 한꺼번에 정리할 수 있는 기능을 보강했습니다.
*   **전원 출석 체크**: 바쁜 수업 시간에 유용한 한 번에 모든 학생 출석 처리 기능을 제공합니다.

### 5. 🎨 브랜딩 및 디자인 최적화
*   **학원 공식 명칭 적용**: '아이디어큐브 아름/SW코딩' 및 '이순남 원장님' 정보로 브랜딩을 완료했습니다.
*   **모바일 최적화**: 모바일 기기에서도 메뉴와 모달창이 깨지지 않도록 반응형 디자인 및 스타일을 완벽하게 조정했습니다.

## 🛠 기술 스택
- **Frontend**: Next.js 14 (App Router), React, Framer Motion
- **Backend/DB**: Supabase (PostgreSQL, Auth)
- **Icons**: Lucide React
- **QR**: html5-qrcode, qrcode.react

---

## 📂 프로젝트 구조
- `src/app/attendance`: 일별/반별 출결 기록 관리
- `src/app/classes`: 학원 반 정보 및 강사 관리 (자동 학생 수 집계)
- `src/app/students`: 학생 정보 및 QR 코드 발급/관리
- `src/app/qr`: 키오스크 모드 (QR 스캔 및 수동 입력)
- `src/app/reports`: 주간 추이, 성실 학생 TOP 5, 월간 출석부(인쇄용)

## 📝 설치 및 실행 방법

1. 환경 변수 설정 (`.env.local`)
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

2. 패키지 설치 및 실행
   ```bash
   npm install
   npm run dev
   ```
